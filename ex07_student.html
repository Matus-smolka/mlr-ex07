A neural network written in NumPy, classifying eight blood-cell types

Exercise 7, task 6. The network is the task 4 script of the notebook with a wider input, wider hidden layers, and a softmax with the cross-entropy loss in place of the squared error. The forward pass and the backward pass are NumPy and plain Python; there is no autograd library and no machine-learning model from a library.

1. The data and its class balance

BloodMNIST (MedMNIST v2, CC BY 4.0), 28 × 28 RGB crops of single cells, eight classes, the official split of 11,959 / 1,712 / 3,421 images. The file is downloaded by download_data.py, which checks the MD5 7053d0359d879ad8a5505303e11de1dc; the data file is not committed.

The classes are uneven but not extremely so: 2,330 neutrophils (19.5%) against 849 lymphocytes (7.1%) in the training split, a ratio of 2.74, and the same proportions in the validation split. The test split's balance is deliberately not reported here — this is the section that motivates the choices, and a test number shown before a choice is made can inform it; the test class counts appear in section 4, as the row sums of the confusion matrix, after the single evaluation. The mitigation question (balanced sampling, section 5b) was decided on the training counts, which is the split the sampling would have changed. Disclosure: during the initial look at the file, a scratch script printed the label distribution of all three splits, test included. It was labels only — no test image was read and no test score existed at that point — and the two questions it could have influenced, whether to mitigate the imbalance and which metric to rank by, were both settled afterwards on validation. It is still a test statistic seen before a decision, so it is stated here rather than left to be found, and the script now prints train and val only.

Because the smallest classes hold only 122 validation images each, one image moves a per-class recall by 0.8%, so overall validation accuracy is the steadier estimate and the one the models were ranked by, with balanced accuracy as the tiebreak (decided in train.py:selection_key, before the test split was opened).

Images are standardized per pixel-channel with the mean and standard deviation of the training split only (standardize(), called from load_splits()); the same two vectors are then applied to validation and test. Pixels that are constant over the training images are only centered.

These are not scattered over the matrix — immature granulocyte appears in all 6 of the cells above, as the true class or the predicted one. That is the boundary the network cannot draw reliably: the immature granulocyte is the precursor stage of the very cells it is mixed up with, so the classes differ by nuclear lobulation and granule maturity. At 28 × 28, with a fully connected first layer and no magnification to fall back on, that distinction rests on a handful of pixels.

Two cautions the numbers give themselves. Platelet is classified perfectly (1.000) — the smallest and least structured object in the set, so the easiest class is also the one where a size-and-texture shortcut is enough; that inflates overall accuracy more than it demonstrates cell recognition. And basophil, the weakest class, is one of the two smallest in the test split (244 images), so its recall carries the widest uncertainty of any figure on this page.

5. Reproducibility and runtime

Seed 0 everywhere, parameters and shuffling from two separate streams, batch 256, BLAS threads fixed at 8 before NumPy is imported (a BLAS reduction splits differently with a different thread count, which moves the last digits). Total 472.03 s on this machine, NumPy 2.3.5, Python on 8 threads.

Three independent runs of python train.py --epochs 50 produced the same results.csv down to the last printed digit — 10 models across 10 fields, 100 values compared, 0 differences, identical MD5 (3652ad2d…). The first run had a wall-clock column and differed from the second only there (61.34 s against 63.85 s for the same model), which is not a reproducibility failure but made diff non-empty; the timings were moved to runtime.json so that a non-empty diff can only mean a real disagreement. Wall-clock per model is in runtime.json.

5b. Was the imbalance worth doing anything about?

No, and that was tested rather than assumed. Class-balanced sampling — every batch column drawing a class uniformly instead of in the natural proportions — was trained against plain sampling at two different architectures and with both optimizers. It lost every time, and in the main comparison it was marginally worse even on the metric built for imbalance: balanced accuracy 0.8568 against 0.8589. At a 2.74 ratio the rare classes are seen often enough already, and oversampling them costs the frequent ones more than it gains the rare ones. The imbalance is therefore handled by measuring it — balanced accuracy, per-class recall and the confusion matrix — and not by touching the training data.

6. What this result does not establish

The numbers are for one public benchmark with a fixed official split and images that were already centre-cropped and downsampled by the dataset's authors. They do not establish that this method is usable for a blood differential in a laboratory, for several separate reasons:

  • A single 28 × 28 crop per cell discards the scale, context and stain information a technician uses, and the crops come from one stained preparation protocol; a different analyser, stain or camera is a different distribution and would need its own measurement.
  • Accuracy is not the quantity a laboratory needs. Pre-sorting cells for a technician to review depends on knowing when the network is unsure, which needs calibration and an abstention threshold; neither is studied here.
  • The errors are not independent across images: cells from the same patient are correlated, and the official split does not make this experiment's error bars patient-aware. The differences between the compared network sizes are within a range that this validation set cannot resolve cleanly.
  • Basophil and lymphocyte have the fewest test images, so their recalls carry the widest uncertainty, and basophils are rare in real blood — a class this small cannot support a claim about detecting a rare population.
  • Nothing here was reviewed against a clinical reference under a protocol; the dataset labels come from an automated pipeline and expert annotation of the original study, not from the workflow this would have to fit into.

A cautious summary: a few-hundred-thousand-parameter network written from scratch beats a softmax baseline on this benchmark by a clear margin and is balanced across the eight classes, which shows the hand-written backward pass works. It is a demonstration of the method, not evidence about clinical use.
