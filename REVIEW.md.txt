Safe softmax: subtract the column maximum

def logsumexp(a):
    m = np.max(a, axis=0, keepdims=True)                  # max over classes, per sample
    return np.log(np.exp(a - m).sum(axis=0, keepdims=True)) + m

def logits_to_proba(logits):
    return np.exp(logits - logsumexp(logits))
 The subtraction runs along axis=0 (classes), per sample/column. After it, the largest exponent is exactly exp(0) = 1, so nothing can overflow. Underflow of the very negative entries to 0.0 is harmless — 0 / (positive sum) is a fine probability.
